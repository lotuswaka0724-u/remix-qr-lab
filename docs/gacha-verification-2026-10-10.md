# ガチャ追加検証結果

検証日：2026-10-10 UTC / 2026-10-11 JST

## 検証条件と境界

- H.264対応のGoogle Chrome 155.0.8059.39（headless）、1280×1800。
- 標準のPlaywright Chromium 141はH.264非対応。Chromeを一時領域に展開して使用。
- localhostの児童ページ上に、実際のCollectionPanel・GachaFilm・gacha-sessionを載せる非保存検証環境を使用。
- 抽選応答と所持状態はブラウザ内の検証値。ログイン済み児童での本番抽選・DB保存ではない。
- 動画・MP3はアプリの既存素材URLをそのまま再生。動画のplaying/ended/errorイベントを人工発火していない。
- 本番の児童データに対する書き込み、テスト児童の作成、確率・景品・ID・ポイント計算・認証・権限・既存連携の変更は行っていない。
- アプリのデザイン・動作コードは変更していない。

## 1. 動画

**確認済み（実メディア、非保存画面）**

- 既存MP4（8.041667秒）を10回連続で最後まで実再生。自然なendedイベント10回。
- 1秒、2.3秒、4.7秒、5.4秒、7秒以降の実フレームを撮影し、装置開放と光の展開を確認。
- 10回とも応答で固定したic_dog「いぬ」が獲得画面に表示。動画終了時に追加の抽選呼び出しなし。
- 毎回3連打しても、非保存の抽選呼び出しは各回1回。検証値は1000→900pt（10回×10pt）。本番ポイントの検証ではない。
- 動画通信を実際に遮断し、破損したMP4応答も返して確認。どちらも確定景品へ遷移し、追加呼び出しなし。

**未確認**

- 実際に児童ログインし、実抽選・保存した景品との一致。iPad Safariの実再生・自動再生制限。

## 2. 音声

**確認済み（再生状態・時刻の実測）**

- 同じ実MP3を再生。音声要素は連続10回後も1個、各終了時の再生中音声0個、動画要素0個。
- 動画待機時の再開は同じ要素で現在の動画時刻から再開。playingが複数回起きるが、複数音声を同時に開始したものではない。
- 100ms間隔の時刻測定で、再生中の映像/音声差は最初の10回で最大0.207秒、再測定の10回で最大0.159秒。
- 実動画再生中の画面移動後、再生中メディア0、同じ景品の結果維持。
- MP3通信遮断により実際に再生不能（media error 4）にした場合も、動画は完走して確定景品表示、追加抽選なし。

**未確認**

- 人による聴感上のタイミング、音量の適切さ、iPadスピーカーでの音声出力。時刻の一致を聴感確認とは扱わない。
- 画面移動と異なり、OSによるバックグラウンド化・端末スリープは実機未確認。

## 3. 実保存

**確認済み（非保存応答・自動テストのみ）**

- 非保存応答の所持品がBOXに表示されることを実画面で確認。
- 保存失敗を応答側に注入するとuncertain状態・景品null・動画0になり、成功表示せず再抽選をブロック。
- gacha-session.test.tsの6件成功。154件の既存カタログ照合成功。

**未確認**

- 本番のポイント消費、所持品保存、再読み込みでの保持、重複登録、実保存失敗。
- 影響のないテスト用児童アカウントが指定・許可されていないため、本番書き込みテストは実行していない。
- Supabase Authのアカウントだけでは、このアプリ独自の児童ログインに代わらない。

**問題あり（既存構造のリスク、実障害未再現）**

- collection.functions.ts:342で所持品を保存し、344以降でポイント消費履歴を別保存する。後段だけ失敗すると所持品だけ保存される可能性がある。
- 画面は成功と誤認せず停止するが、保存の完全な整合性を保証する構造ではない。
- 複数端末・再読み込みをまたぐ重複防止は今回の同一セッション試験では保証できない。
- 既存保存・連携の変更は禁止されているため変更していない。

## 4. 負荷

**確認済み（短期・検証環境）**

- 10回完走。クリックから結果まで平均8.889秒（動画自体8.042秒、検証応答待ち100msを含む）。
- 音声要素は1個、各終了後の再生中音声0、アプリエラー0。
- GC後のJS使用量は約19.15MB→20.05MB。計測記録と開発モードを含み、長期リークなしとは断定しない。

**問題あり（検証環境で実測）**

- 多数の動画フレーム落ちを確認。終盤の記録例：193フレーム中107〜129フレーム落ち。
- 最大204msの長時間処理を確認。滑らかさの合格とは扱わない。
- 実行環境のソフトウェア描画・開発モード・計測の影響と、画面固有の影響を切り分けられていない。

**未確認**

- iPad実機、長時間の連続利用、実ネットワーク下の保存を含む開始時間、聴感。
