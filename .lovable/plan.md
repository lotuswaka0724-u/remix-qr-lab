# 完成済みアイコン適用とガチャ演出改善

## 実装内容

1. `public/prizes/icons/` に実在する51点だけを、対応する既存景品IDへ登録します。
   - ファイル名と既存IDを1対1で対応させます。
   - 未完成9点は絵文字・Legacy表示を維持します。
   - 画像の削除・移動・加工・生成は行いません。

2. 現在のガチャ画面をベースに、短い一連の演出へ整理します。
   - 抽選中：装置とカプセルの動きを段階的に強めます。
   - 停止・溜め：結果直前に短く静止します。
   - 結果：画面中央の専用表示へ切り替え、アイテムを拡大・反動・定位置の順で表示します。
   - レアリティ、名前、GET、重複情報、アイテムBOXへの導線を中央結果表示内に残します。
   - 結果を閉じるまで再抽選できない状態を維持します。

3. レアリティ別に既存の色・音・エフェクトを段階化します。
   - N / R / SR / SSR / GOLD / BLACK の既存値をそのまま使います。
   - 高レアリティほど光・粒子・出現の強さを増やします。
   - 怖い暗転や強すぎる点滅は使いません。

4. アイテム出現と獲得音を同じ結果開始処理で同時に発火します。
   - 抽選サーバー呼び出しは1回だけです。
   - 結果確定後は表示タイムラインだけを進め、再抽選しません。

## 変更範囲

- `src/lib/collection-catalog.ts`：存在する完成済みアイコン51点の素材登録のみ
- `src/components/CollectionPanel.tsx`：ガチャ表示・状態遷移・音同期のみ
- `src/styles.css`：ガチャ専用アニメーションと表示のみ
- `roadmap.md`：今回の作業項目更新

- 154景品の基準照合でID・名前・カテゴリ・レアリティ・初期所持・排出設定・順序が不変
- 51点の画像ファイル存在、PNG、透過、ID対応を確認
- 未完成9点が従来表示へ戻ることを確認
- ガチャの抽選呼び出しが1回、演出中と結果表示中の連打が無効であることを確認
- 中央結果表示、短い溜め、拡大・反動、レアリティ差、音同期を画面で確認
- アイテムBOX、QR、宿題、ポイント、児童管理、先生画面に変更がないことを確認
- 画像生成・外部API・有料サービスは使用しません
